# BatchPrinter Overview
- Purpose: Native macOS app to scan folders and batch print Word/PDF files with queue controls.
- Core workflows: folder selection, file scanning, optional preprocess to PDF, batch print, log tracking.
- Word docs are printed/exported via Microsoft Word AppleScript automation for rendering fidelity.
- PDF docs can be printed directly or transformed during preprocess/export paths.
- Current UX highlights:
  - Auto-scan after successful folder selection.
  - Scan uses 'Scan subfolders' state and logs whether it is On/Off.
  - Queue sortable by File table header (ascending/descending).
  - Preprocess prompts destination each run: system temp or user-selected folder.
  - Page range supports N, N-M, and explicit comma-separated pages (order preserved).
