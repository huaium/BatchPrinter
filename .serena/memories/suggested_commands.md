# Suggested Commands
- Build app:
  - `xcodebuild -project BatchPrinter.xcodeproj -scheme BatchPrinter -configuration Debug -sdk macosx -derivedDataPath /tmp/BatchPrinterDerivedData build`
- Inspect changes:
  - `git status --short`
  - `git diff`
- Find code quickly:
  - `rg --files`
  - `rg -n "<pattern>" BatchPrinter`
- View snippets:
  - `nl -ba <file> | sed -n 'start,endp'`
- Typical macOS shell utilities used here:
  - `ls`, `cd`, `cat`, `sed`, `find`, `open`, `pbcopy`.
